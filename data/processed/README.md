# Processed Dataset Outputs

This folder stores generated training metadata for binary damage classification.

## Files

- `train_manifest.csv`: Base manifest with one row per tile pair and normalized label fields.
- `train_split.csv`: Training subset generated by `scripts/split_dataset.py`.
- `val_split.csv`: Validation subset generated by `scripts/split_dataset.py`.
- `test_split.csv`: Test subset generated by `scripts/split_dataset.py`.
- `class_imbalance_summary.csv`: Row and class-distribution summary for each split.
- `class_weights.json`: Class weights computed from the train split.
- `seed_scan_report.json`: Candidate seed scores and selected-seed decision report.

## Build / Split Commands

```powershell
Set-Location "D:\JupyterProject"
py scripts\build_train_manifest.py
py scripts\split_dataset.py --ratios 0.7,0.15,0.15 --seed 42 --weight-formula balanced
py scripts\split_dataset.py --ratios 0.7,0.15,0.15 --seed-list 42,2026,1337 --weight-formula balanced
py scripts\split_dataset.py --ratios 0.7,0.15,0.15 --seed 42 --scan-seeds 100 --weight-formula balanced
```

## Notes

- Split assignment is done at `event_id` level to reduce leakage.
- Stratification target is `binary_damage` distribution across splits.
- Weight formulas available: `balanced`, `neg_pos`, `log_smoothed`.
- If `--seed-list` is provided, the script evaluates all candidate seeds and picks the lowest-score split.
- `--scan-seeds N` evaluates seeds in `[seed, seed+N-1]` and chooses by class-balance-focused objective.
